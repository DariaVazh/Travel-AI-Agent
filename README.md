# Free Penguins — Travel Helper 🐧

**Travel Helper** — ИИ-агент для планирования путешествий в Telegram. Проект команды **Free Penguins** для **Ostrovok Hackathon 2026**, кейс **«О!дин запрос»**.

> Скажи, куда хочешь отправиться, — остальное устроит агент!

- **Telegram-бот:** [@travel_O_island_bot](https://t.me/travel_O_island_bot)
- **Исходный код:** [free-penguins](https://github.com/ostrovok-hackathon-2026/free-penguins)
- **Презентация и видеообзор:** https://disk.yandex.ru/d/po23Mq14lyLmdw

## О решении

Пользователь рассказывает о желаемой поездке **на естественном языке**: куда и когда хочет поехать, откуда выезжает, какой у него бюджет и что важно при выборе транспорта и гостиницы. Travel Helper уточняет недостающие детали, обращается к подключённым сервисам и помогает сравнить варианты.

В отличие от обычного набора фильтров, ИИ-агент интерпретирует свободный запрос, учитывает предпочтения пользователя и объясняет, почему рекомендует конкретный вариант.

- **Диалоговое планирование:** понимание свободных запросов и последовательное уточнение условий поездки.
- **Поиск транспорта и размещения:** работа с данными о перелётах, железнодорожных маршрутах и гостиницах через внешние источники.
- **Сравнение альтернатив:** подбор ограниченного набора подходящих вариантов; выбор самого дешёвого, самого быстрого или сбалансированного по приоритетам пользователя.
- **Оценка привлекательности:** сравнение предложений с учётом стоимости, времени и других факторов, важных пользователю.
- **Прогноз погоды:** информация о погоде для направления и дат путешествия (в демонстрации используется Open-Meteo).
- **Персонализация:** сохранение пользовательских данных и информации о бронированиях в PostgreSQL для последующих рекомендаций.
- **Сценарий оформления:** в презентации показана **демонстрационная** оплата и подтверждение бронирования. Реальное списание средств не заявлено.

## Пример взаимодействия

**Запрос пользователя:**

> Хочу съездить в Казань в начале ноября, выехать из Санкт-Петербурга 4 ноября и вернуться через неделю. Бюджет — 300 000 ₽. Хочу гостиницу с приятной атмосферой.

**Что делает Travel Helper:** уточняет необходимые данные, предлагает варианты поездки, сообщает прогноз погоды, сравнивает предложения по цене, скорости и общему удобству и помогает выбрать подходящий вариант.

Скриншоты такого сценария приведены в презентации команды.

## Архитектура

```text
Пользователь
     │
     ▼
Telegram-бот (aiogram)
     │
     ▼
Python Backend (FastAPI)
     ├── LLM через OpenRouter — понимание запроса и выбор действий
     ├── Python + внешние API — поиск и сравнение предложений
     └── PostgreSQL — данные и предпочтения пользователей
```

Для развертывания используется **Docker / Docker Compose**. Приложение включает следующие компоненты:

| Компонент | Назначение |
| --- | --- |
| `app` | FastAPI backend, обработка запросов и координация компонентов |
| `bot` | Telegram-бот на aiogram |
| PostgreSQL | База данных; может быть развернута отдельным Docker-сервисом либо использоваться как внешняя БД |

### Модель и интеграции

Модель **`nvidia/nemotron-3-ultra-550b-a55b:free`**. Интеграция с LLM выполняется через **OpenRouter**; фактически используемая модель задаётся переменной `OPENROUTER_MODEL`.

| Интеграция | Назначение |
| --- | --- |
| Авиасейлс / туристический API | Поиск и сравнение вариантов авиаперелётов |
| 2GIS | Географические данные и информация о местах |
| Яндекс Расписания | Данные о транспортных маршрутах и расписаниях |
| Open-Meteo | Прогноз погоды (показан в демонстрации) |
| PostgreSQL | Пользовательские данные, предпочтения и сведения о бронированиях |

Доступность отдельных сценариев зависит от подключённых API и их ключей. Источник данных о гостиницах в презентации отдельно не назван.

## Требования для запуска

- Docker Desktop либо Docker Engine с Docker Compose;
- Git;
- доступ к интернету;
- необходимые API-ключи и токен Telegram-бота.

Устанавливать Python и зависимости вручную не требуется: они устанавливаются при сборке Docker-образов.

## Быстрый запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ostrovok-hackathon-2026/free-penguins.git
cd free-penguins
```

### 2. Создать `.env`

Linux / macOS:

```bash
cp .env.example .env
```

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Укажите в `.env` необходимые значения:

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота |
| `OPENROUTER_API_KEY` | Ключ доступа к OpenRouter |
| `OPENROUTER_MODEL` | Идентификатор модели LLM |
| `TWOGIS_API_KEY` | Ключ API 2GIS |
| `TRAVELPAYOUTS_TOKEN` | Токен туристического API |
| `YANDEX_RASP_KEY` | Ключ Яндекс Расписаний |
| `DB_HOST` | Адрес PostgreSQL |
| `DB_PORT` | Порт PostgreSQL |
| `DB_NAME` | Название базы |
| `DB_USER` | Пользователь базы |
| `DB_PASSWORD` | Пароль базы |
| `DB_SSL` | Использование SSL при подключении |

Для воспроизведения конфигурации модели из презентации:

```dotenv
OPENROUTER_MODEL=nvidia/nemotron-3-ultra-550b-a55b:free
```

Параметры подключения к PostgreSQL должны соответствовать вашей конфигурации `docker-compose.yml` или внешней базы данных. Внутренний порт PostgreSQL обычно `5432`; если база доступна на хосте через `5433`, это **другой адрес подключения**.

### 3. Запустить сервисы

```bash
docker compose up --build
```

Для фонового запуска:

```bash
docker compose up -d --build
```

### 4. Проверить работу

- **Telegram-бот:** [@travel_O_island_bot](https://t.me/travel_O_island_bot) — отправьте `/start`.
- **FastAPI:** http://localhost:8080
- **Проверка backend:** http://localhost:8080/health

> Адреса FastAPI и `/health` приведены согласно текущей инструкции проекта; перед сдачей проверьте, что они соответствуют фактической конфигурации.

## Управление контейнерами

```bash
# Состояние сервисов
docker compose ps

# Логи Telegram-бота
docker compose logs -f bot

# Логи backend
docker compose logs -f app

# Логи PostgreSQL (при наличии сервиса db)
docker compose logs -f db

# Остановить сервисы
docker compose down
```

При использовании именованных Docker volumes команда `docker compose down` сохраняет их данные. **Не используйте `docker compose down -v`, если требуется сохранить базу.**

## Секреты и безопасность

- `.env.example` — шаблон переменных без реальных секретов;
- `.env` — локальные секреты, файл должен быть исключён из Git;
- `secrets.env.age` — зашифрованный файл с секретами для организаторов хакатона.

Файл `secrets.env.age` создан с помощью утилиты [`age`](https://github.com/FiloSottile/age) и публичного ключа организаторов. Для его расшифровки нужен соответствующий приватный ключ.

Пример расшифровки для владельца приватного ключа:

```bash
age --decrypt -i /path/to/private-key -o .env secrets.env.age
```
