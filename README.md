# Free Penguins — Ostrovok Hackathon 2026

Проект команды Free Penguins для Ostrovok Hackathon 2026.

## Требования

- Docker Desktop с запущенным Docker Engine
- Docker Compose
- Git для клонирования репозитория

Локальная установка Python и библиотек не требуется.

## Запуск

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/ostrovok-hackathon-2026/free-penguins.git
   cd free-penguins
   ```

2. Настроить переменные окружения

Создать локальный `.env` на основе `.env.example`.

**Windows (PowerShell):**

```
Copy-Item .env.example .env
```

**Linux/macOS:**

```
cp .env.example .env
```

Открыть `.env` и заполнить необходимые API-ключи и токены.

Настоящие ключи предоставляются участникам команды отдельно и не хранятся в GitHub.

Важно:

- Не удаляйте и не переименовывайте переменные из шаблона.
    
- Не публикуйте содержимое `.env`.
    
- При изменении переменных окружения пересоздайте контейнер.
    


3. Собрать и запустить приложение:

   ```bash
   docker compose up --build
   ```

4. Проверить работоспособность:

   - Приложение: http://localhost:8080/
   - Healthcheck: http://localhost:8080/health
   - Ожидаемый ответ: `{"status":"ok"}`

## Проверка контейнеров

```bash
docker compose ps
```

Статус сервиса `app` должен быть `healthy`.

## Остановка

```bash
docker compose down
```

## Безопасность

- `.env` содержит настоящие API-ключи и исключён из Git.
    
- `.env.example` содержит только шаблон переменных без секретов.
    
- `.dockerignore` исключает `.env` из контекста сборки.
    
- API-ключи нельзя добавлять в исходный код, коммиты или Dockerfile.
    
- При компрометации ключа необходимо отозвать его и выпустить новый.
    

## Текущее состояние

В проекте настроена Docker-инфраструктура для запуска Python-приложения.

В репозиторий добавлены модули поиска, провайдеров, работы с внешними API и корзины. Интеграция компонентов в единый пользовательский сценарий продолжается.

HTTP-приложение предоставляет эндпоинт проверки состояния `/health`.
